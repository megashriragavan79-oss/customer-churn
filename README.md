# Customer Churn: Responsible ML Framing Pack

Contents: - `ml_problem_framing_memo.md` - `responsible_data_card.md` -
`risk_register.md` - `baseline_analysis.ipynb`

The notebook profiles the supplied CSV and demonstrates a majority-class
baseline. It deliberately does not train an ML model because 12 records
are not enough for reliable model evaluation.

Run the notebook in Jupyter or Google Colab. Update `DATA_PATH` if the
CSV is stored elsewhere.

Important: `responsible-data-card-template.htm` was inspected; its
contents are a RabTech Academy internship webpage, not a
responsible-data-card template. No structure from that page has been
treated as a data-card template.
